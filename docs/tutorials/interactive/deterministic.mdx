The `cccc-io` crate glues legacy deterministic-transport files: ISOTXS
multigroup cross-section libraries, RTFLUX/ATFLUX/RZFLUX flux files, and a
1D/2D/3D PARTISN input writer with ISOTXS nuclide mapping. No transport
solving is performed here.

## ISOTXS libraries

An ISOTXS library declares its group count once (`ISOTXS <ngroups>`), then
lists one `NUCLIDE <label> <zaid> <ngroups>` record plus total cross sections
per nuclide. The demo below parses pasted library text into a JSON summary of
nuclide labels, ZAIDs, and total cross sections per group.

## Flux files and PARTISN decks

RTFLUX/ATFLUX/RZFLUX point-flux files parse in the browser below
(`parseRtflux` with the `rtflux`|`atflux`|`rzflux` kind-switch mirroring
Python) and render a chart-only per-point flux profile (one grouped-bar trace
per energy group, following the ISOTXS precedent). PARTISN decks also render
and validate in the browser (`partisnRender`, `partisnValidate`): the demo
builds a structured deck dict with the exact keys `title`, `dim`, `zones`
(each `id`, `material`, `isotxs_labels`, `density`), and optional `source`
(mirroring the Python `partisn_render`/`partisn_validate` shape — no
camelCase aliases), and validates zone labels against a pasted ISOTXS library
parsed with `parseIsotxs`. ISOTXS totals render as a grouped bar chart
(chart-only).
